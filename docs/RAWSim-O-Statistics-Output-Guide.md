# RAWSimO Simulation Output Guide (Updated)

This document describes all simulation output files produced in the statistics directory and introduces a new per-bot trajectory CSV: `botlocations_detailed.csv`.

Output directory: `/app/out/<run-id>/`

## New: botlocations_detailed.csv

- Purpose: Per-bot, per-timestep location snapshots for downstream model consumption.
- Generated by: `SimulationObserver` (position polling) in `RAWSimO.Core`.
- File: `botlocations_detailed.csv`
- Columns: `BotID;Tier;X;Y;Timestamp;Task`
- Sampling: Same schedule as location polling (`STEP_LENGTH_POSITION_POLL` or intense mode).
- Notes:
  - `Task` is the current `BotTaskType` for the bot at the sample time.
  - Timestamp is simulation seconds since `StatTimeStart`.

## Heat / Snapshot / Progression Files

- `locationspolled.heat`: Polled bot positions for heatmap visualization (without BotID).
- `storagelocationinfopolled.heat`: Heatmap-style storage location information samples.
- `trips.heat`: Trip counts aggregated per connection.

- `performance.csv`: Memory usage and controller timing snapshots.
- `inventorylevel.csv`: Inventory level snapshots and inversion metrics.
- `bundleordersituations.csv`: Backlog and assignment situation snapshots.
- `stationprogression.csv`: Station activity snapshots.
- `botinfoprogression.csv`: Aggregated robot status counts (not positions).
- `wellsortedness.csv`: Sortedness snapshots grouped by path time to output stations.

- `itemprogression.csv`: Item handling progression over time.
- `bundleprogression.csv`: Bundle handling progression over time.
- `orderprogression.csv`: Order handling progression over time.
- `bundleplacementprogression.csv`: Bundle placement progression.
- `orderplacementprogression.csv`: Order placement progression.
- `collisionprogression.csv`: Collision count progression.
- `tripscompleted.csv`: Completed trips progression.
- `traveleddistanceprogression.csv`: Traveled distance progression.

## End-of-Run Summary Files

- `statistics.txt`: Human-readable run summary report.
- `stationstatistics.csv`: Final per-station statistics.
- `itemdescriptionstatistics.csv`: Final per-item-description statistics.
- `connectionstatistics.csv`: Connection/route usage statistics.
- `footprint.csv`: Aggregated main KPI footprint.
- `pathfinding.csv`: Path planner statistics (requests, timing, etc.).

## Metadata Files

- `instance.txt`: Instance name.
- `setting.txt`: Setting name.
- `controller.txt`: Controller name.

## Per-Bot Trajectories vs. Heatmap

- `botlocations_detailed.csv` now provides explicit `BotID` positions at each sampled timestep.
- `locationspolled.heat` remains useful for heatmaps but does not include BotID.

## Consumption Tips

- CSV delimiter: `;` (semicolon) as defined by `IOConstants.DELIMITER_VALUE`.
- Numeric formatting uses invariant culture (`.` decimal separator).
- Timestamps are simulation seconds since start.

## Versioning

This guide reflects the RAWSimO Core changes that automatically emit `botlocations_detailed.csv` during simulation. Downstream consumers can rely on this file for per-robot trajectory analysis without tapping into visualization or internal memory structures.

## 文件分类

### A. **实时进度追踪文件** (Progression CSV)

这些文件记录整个仿真过程中，某个关键指标随时间的变化。每一行代表一个采样时间点。

#### 1. **itemprogression.csv**

- **作用**: 追踪物品（Item）处理的进度
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `ItemProgressionDatapoints`
- **内容**: 各个时刻的物品流入、处理、完成情况
- **时间粒度**: 仿真步长（默认 0.05秒）

#### 2. **bundleprogression.csv**

- **作用**: 追踪货箱/包裹（Bundle）的处理进度
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `BundleProgressionDatapoints`
- **内容**: 货箱的请求、处理、完成统计
- **用途**: 分析物流中心货物周转效率

#### 3. **orderprogression.csv**

- **作用**: 追踪订单（Order）的处理进度
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `OrderProgressionDatapoints`
- **内容**: 订单的创建、拣选、打包、完成各阶段数据
- **关键指标**: 待处理订单数、已完成订单数

#### 4. **bundleplacementprogression.csv**

- **作用**: 追踪货箱在存储位置的放置进度
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `BundlePlacementProgressionDatapoints`
- **内容**: 货箱存储位置分配、放置完成情况

#### 5. **orderplacementprogression.csv**

- **作用**: 追踪订单分配到工作站的进度
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `OrderPlacementProgressionDatapoints`
- **内容**: 订单在各工作站的分配分布

#### 6. **collisionprogression.csv**

- **作用**: 追踪碰撞事件
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `CollisionProgressionDatapoints`
- **内容**: 机器人之间的碰撞次数随时间的变化
- **用途**: 评估路径规划和冲突解决策略的效果

#### 7. **traveleddistanceprogression.csv**

- **作用**: 追踪机器人总行驶距离
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → 定时采样
- **内容**: 各个时刻所有机器人的累计行驶距离
- **关键指标**: 整体物流效率评估

---

### B. **快照统计文件** (Snapshot CSV)

这些文件以固定时间间隔采样系统状态，记录关键系统指标的"快照"。

#### 8. **performance.csv**

- **作用**: 系统性能快照采样
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → `PollPerformance()`
- **内容**: 机器人状态、任务分配、工作负载分布等
- **采样频率**: 默认每 10 仿真秒一次
- **用途**: 分析系统在不同运行时期的性能表现

#### 9. **inventorylevel.csv**

- **作用**: 库存水平快照
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → `PollInventoryLevel()`
- **内容**: 各存储位置的物品数量快照
- **用途**: 评估存储策略效果

#### 10. **bundleordersituations.csv**

- **作用**: 货箱和订单情况快照
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs`
- **内容**: 待处理/处理中/已完成的货箱和订单快照
- **用途**: 了解系统的处理能力和吞吐量

#### 11. **stationprogression.csv**

- **作用**: 工作站活动快照
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → `PollStations()`
- **内容**: 各工作站的忙闲状态、处理的订单数等
- **用途**: 分析工作站利用率和负载均衡

#### 12. **botinfoprogression.csv**

- **作用**: 机器人信息聚合统计（**NOT** 位置数据）
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → `PollBots()`
- **内容**: 机器人总数、忙碌、闲置、损坏状态统计
- **重要**: 这个文件**不包含个别机器人的位置**，只有聚合计数
- **用途**: 评估机器人资源利用情况

#### 13. **wellsortedness.csv**

- **作用**: 分拣度量（Sortedness）快照
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → `PollWellSortedness()`
- **内容**: 物品分拣有序性度量
- **用途**: 评估拣货策略效果

---

### C. **热力图文件** (Heat/Density Log)

这些文件记录位置访问频率，用于热力图可视化。

#### 14. **locationspolled.heat** ⭐ **最关键的路径数据**

- **作用**: **机器人位置采样热力图** — 这是唯一包含机器人位置时间序列的文件
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs` → `PollBotLocations()`  
  → `RAWSimO.Core/Statistics/DataPoint.cs`
- **内容格式**: 每行记录 `(Tier, X, Y, 访问次数, 时间戳)`
- **采样频率**: 定时采样（默认每 10 仿真秒一次）
- **重要限制**:
  - ⚠️ **不包含 Bot ID**，所以无法从该文件单独重构个别机器人的精确轨迹
  - 可用于热力图、occupancy 分析、区域访问频率等
- **用途**:
  - 可视化高频访问区域
  - 分析物流中心的流量热点
  - 评估仓库布局优化机会

#### 15. **storagelocationinfopolled.heat**

- **作用**: 存储位置访问热力图
- **生成位置**: `RAWSimO.Core/Statistics/SimulationObserver.cs`
- **内容**: 各存储位置的访问频率热力数据
- **用途**: 分析 ABC 库存分类策略效果、优化存储位置分配

#### 16. **trips.heat**

- **作用**: 时间无关的行程计数热力图
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `TripsDatapoints`
- **内容**: 每条路径段（waypoint-to-waypoint）的行程总数
- **用途**: 分析高频路线，用于基础设施规划

---

### D. **最终汇总统计文件** (Summary/Report)

这些文件在仿真结束时生成，包含最终统计数据。

#### 17. **statistics.txt**

- **作用**: 人类可读的仿真运行摘要报告
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `GetReport()`
- **内容**:
  - 仿真基本信息（运行时间、配置名称等）
  - 全局统计指标汇总
  - 主要 KPI（吞吐量、平均周期时间等）
  - 各系统模块的性能总结
- **格式**: 纯文本，便于人工审阅和报告生成

#### 18. **stationstatistics.csv**

- **作用**: 每个工作站的最终统计汇总
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `FinalStationStatistics`
- **内容**: 各工作站的处理订单数、平均响应时间、利用率等
- **用途**: 评估工作站设置和负载分配策略

#### 19. **itemdescriptionstatistics.csv**

- **作用**: 物品类型（Item Description）的最终统计
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `ItemDescriptionStatistics`
- **内容**: 各物品类型的请求数、处理数、平均周期时间等
- **用途**: 分析物品类型对系统的影响

#### 20. **connectionstatistics.csv**

- **作用**: 路径连接（Waypoint-to-Waypoint）的最终统计
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → 从 waypoint stats 聚合
- **内容**: 各路径段的行程数、平均距离等
- **用途**: 评估网络布局效率、优化路由

#### 21. **footprint.csv**

- **作用**: 仿真结束时的"足迹"汇总
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `Footprint()`
- **内容**: 最终的关键指标快照
- **用途**: 快速查看运行结果概览

#### 22. **pathfinding.csv**

- **作用**: 路径规划算法的统计数据（**不是机器人实际路径**）
- **生成位置**: `RAWSimO.Core/InstanceStatistics.cs` → `PathfindingDatapoints`
- **内容**: 路径规划请求数、计算时间、算法效率指标等
- **用途**: 评估路径规划算法的性能和可扩展性

---

### E. **配置记录文件** (Metadata)

#### 23. **instance.txt**

- **作用**: 本次仿真所用的实例名称记录

#### 24. **setting.txt**

- **作用**: 本次仿真所用的设置名称记录
- **内容**: 单行文本，仅记录设置名称

#### 25. **controller.txt**

- **作用**: 本次仿真所用的控制器配置名称记录
- **内容**: 单行文本，仅记录控制器名称

## 重要注意事项

### ⚠️ 机器人个体路径数据的获取限制

**问题**: 用户可能期望找到"机器人 #5 在时刻 t=10.2s 的位置"这样的数据。

**现状**:

1. `locationspolled.heat` 记录了 `(x, y, count, timestamp)`，但**不包含 Bot ID**
2. 实际的机器人路径存在内存中，由 `BotNormal` / `BotHazard` 类中的 `CurrentPath` 属性管理
3. 源码路径: `RAWSimO.Core/Bots/BotNormal.cs`, `RAWSimO.Core/Bots/BotHazard.cs`
4. 可视化代码: `RAWSimO.Visualization/Rendering/SimulationVisual2D.cs` 读取这些在内存路径并绘制

**要获取个别机器人的路径数据，有以下选项**:

1. **修改源码** — 在 `SimulationObserver.cs` 的 `PollBotLocations()` 方法中增加 Bot ID 记录  
   位置: `RAWSimO.Core/Statistics/SimulationObserver.cs` line ~XXX

2. **使用可视化输出** — 从 AvaloniaClient/WebServer 的视觉渲染中提取机器人位置轨迹（实时读取）

3. **后处理分析** — 使用其他指标（碰撞、行驶距离变化、性能数据）作为间接的性能评估

## 文件格式说明

### CSV 格式

- 标准逗号分隔值
- 第一行通常为列标题（由生成代码决定）
- 可用 Excel、Python pandas、R 等工具分析

### Heat/Log 格式

- 自定义格式，用于热力图/密度可视化
- 通常为 `Tier,X,Y,Count,Timestamp` 或类似格式
- 由 RAWSimO 的可视化工具专用解析

### TXT 格式

- 纯文本，人类可读
- `statistics.txt` 为多行报告格式
- 其他 `.txt` 仅单行元数据

## 总结

- **如需完整的机器人轨迹数据，不能仅依赖输出文件**，需要：
  - 修改代码以包含 Bot ID 到 `locationspolled.heat`
  - 或实时从仿真 API（如 WebServer SSE）读取位置数据
  
- **现有文件足以进行系统级性能评估**（吞吐量、效率、碰撞等）

- **`statistics.txt` 和 progression CSV 文件是分析的主要来源**
