# 基于数字孪生的多AGV协同调度管理与仿真系统 - 测试计划

## 1. 测试范围

### 1.1 测试系统

| 序号 | 测试系统 | 版本 |
|------|----------|------|
| 1 | 基于数字孪生的多AGV协同调度管理与仿真系统 (RAWSimO WebServer) | v1.0 |
| 2 | 多场景通用AGV协同调度管控云平台 (mir_fe) | v1.0 |

### 1.2 测试环境要求

- 操作系统: Linux (Docker 部署)
- 后端: .NET 10.0, ASP.NET Core
- 前端: Vue.js 2.x + Element UI
- 测试工具: 浏览器 (Chrome/Edge), curl, Postman

## 2. 测试实例与配置

### 2.1 测试实例文件

| 用途 | 实例文件 | 说明 |
|------|----------|------|
| 基础功能测试 | `1-3-3-15-64.xinst` | 1层3台AGV、3补货站、15拣选站、64料架 |
| 大规模性能测试 | `Repo300AGV.xlayo` | 300台AGV布局，用于200+台AGV接入测试 |
| 3000+任务性能测试 | `1-15-51-150-3041.xinst` | 150台AGV、51补货站、3041料架 |

### 2.2 配置文件

| 用途 | 配置文件 | 说明 |
|------|----------|------|
| 仿真设置 | `steadysetting.xsett` | 稳态设置 |
| 大规模仿真设置 | `SimpleItem-Fill-200-200-172800.xsett` | 200x200 SKU，持续172800s |
| 调度控制 | `HardwareTestFAR.xconf` | FAR路径规划控制器 |
| 资源包 | `Resources.zip` | 仿真资源文件 |

### 2.3 性能测试参数

- AGV数量: >= 200 台
- 待调度任务数: >= 3000 个
- 目标平均任务响应时间: < 3 秒

## 3. 测试用例

### 3.1 AGV管控系统测试

#### TC-01: 概要面板

- **检测项目**: 系统支持显示 AGV 数量、任务数量、已接入站点数量、告警状态
- **前置条件**: 系统正常运行，仿真已启动
- **测试步骤**:
  1. 启动仿真（使用 `1-3-3-15-64.xinst`）
  2. 进入仿真可视化页面
  3. 检查概要面板区域
  4. 验证显示的AGV数量与实例配置一致
  5. 验证显示的任务数量（Pending/Open/Completed）
  6. 验证显示的站点数量
  7. 验证告警状态信息
- **预期结果**: 概要面板正确显示 AGV 总数、任务统计（待分配/执行中/已完成）、站点数量、告警状态
- **判定标准**: 所有数据项均正确显示且实时更新

#### TC-02: 实时监控系统

- **检测项目**: 系统支持显示已接入AGV的实时位置
- **前置条件**: 仿真运行中
- **测试步骤**:
  1. 在可视化页面观察AGV分布
  2. 等待若干仿真步后再次观察
  3. 验证AGV位置在渲染图中实时更新
- **预期结果**: 渲染图中红色圆点（AGV）位置随仿真推进实时变化，每个AGV显示朝向指示线
- **判定标准**: AGV位置每100ms内更新，无明显延迟

#### TC-03: 车辆数据统计

- **检测项目**: 系统支持显示AGV状态的统计信息
- **前置条件**: 仿真运行中

#### TC-04: 任务数据统计

## 4. 测试模式

系统提供 **测试模式** 功能，在仿真可视化页面通过 "Test Mode" 按钮进入。

### 4.1 测试模式功能

- 选择测试编号 (TC-01 ~ TC-20)
- 自动加载对应测试所需的实例和配置
- 实时显示测试指标和结果
- 生成测试报告

### 4.2 测试模式数据指标

| 指标 | 说明 | 对应测试项 |
|------|------|-----------|
| AGV Count | 当前接入AGV总数 | TC-01, TC-06 |
| Task Stats | Pending/Open/Completed 任务数 | TC-01, TC-04, TC-14 |
| Station Count | 输入站/输出站数量 | TC-01, TC-09 |
| Bot Positions | 所有AGV实时位置和朝向 | TC-02, TC-11 |
| Bot States | AGV状态统计（空闲/忙碌/充电） | TC-03 |
| Health Status | 系统健康状态 | TC-12 |
| Response Time | API响应时间 | TC-16 |
| Waypoint Count | 路径节点数量 | TC-10 |
| Error/Alert Count | 错误和告警数量 | TC-19, TC-20 |

## 5. 性能测试方案

### 5.1 AGV规模测试

```text
测试实例: Repo300AGV.xlayo (300台AGV)
配置: SimpleItem-Fill-200-200-172800.xsett
控制器: HardwareTestFAR.xconf
验证: 所有300台AGV正常接入和运行
```

### 5.2 任务规模测试

```text
测试实例: 1-15-51-150-3041.xinst (3041个料架)
配置: steadysetting.xsett
控制器: HardwareTestFAR.xconf
步骤:
  1. 启动仿真
  2. 通过 AppendTasks API 批量追加 3000+ 任务
  3. 记录每次调用的响应时间
  4. 计算平均响应时间
判定: 平均响应时间 < 3秒
```

### 5.3 综合规模测试 (>200 AGV + >3000 任务)

```text
测试实例: Repo300AGV.xlayo (300台AGV)
配置: TestScale-300AGV-5000Task.xsett (WarmupOrderCount=5000, OrderCount=5000)
控制器: HardwareTestFAR.xconf
步骤:
  1. 加载 Repo300AGV.xlayo + TestScale-300AGV-5000Task.xsett + HardwareTestFAR.xconf
  2. 启动仿真
  3. 验证 AGV 接入数量 >= 200 (实际 300 台)
  4. 等待仿真自动生成任务，或通过 AppendTasks API 追加额外 3000+ 任务
  5. 记录每次 AppendTasks API 的响应时间
  6. 计算平均任务响应时间
判定:
  - AGV 接入数量 >= 200: PASS
  - 待调度任务数 >= 3000: PASS
  - 平均任务响应时间 < 3秒: PASS
  - 三项均通过则综合判定 PASS
```

## 6. 测试结果判定标准

| 等级 | 说明 |
|------|------|
| PASS | 测试结果完全符合预期 |
| PASS(W) | 测试结果基本符合，存在轻微问题但不影响功能 |
| FAIL | 测试结果不符合预期，需修复后重测 |
| N/A | 该测试项不适用于当前测试环境 |
